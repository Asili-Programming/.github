# Asili Programming

**Asili** (Origin / Nature) is a programming language whose vocabulary and structure are written in Swahili. Its toolchain, **Pata**, gives one pipeline for learning, scripting, and embedded-style targets.

## Repositories

| Repository | What it is |
|---|---|
| [Asili](https://github.com/Asili-Programming/Asili) | The language and the Pata toolchain: compiler, evaluator, native backend, CLI, formatter, linter, and the Mwalimu language server |
| [asili-vscode](https://github.com/Asili-Programming/asili-vscode) | VS Code extension: syntax highlighting, snippets, and the Mwalimu language server |
| [asili-playground](https://github.com/Asili-Programming/asili-playground) | Browser playground: programs compile to WebAssembly and run client-side |
| [asili-programming.github.io](https://github.com/Asili-Programming/asili-programming.github.io) | Project website: https://asili-programming.github.io |
