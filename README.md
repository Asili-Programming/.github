# Asili-Programming `.github`

Organization-wide defaults and the public profile page for [Asili-Programming](https://github.com/Asili-Programming).

- `profile/README.md`: the organization profile shown on github.com/Asili-Programming.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`: used by any repository in the organization that does not define its own.
- `ISSUE_TEMPLATE/` and `PULL_REQUEST_TEMPLATE.md`: default templates for repositories without their own.

The [Asili](https://github.com/Asili-Programming/Asili) repository keeps its own copies of these files, and those take precedence there. When the Asili copies change, update these defaults to match.
